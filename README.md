# Inner Current (Внутренний ток) ⚡ — Архитектура счастья

> **Инженерная система и машина для диагностики счастья, целостности и сверхпроводимости человеческого контура.**  
> Входит в состав зонтичной мета-системы **«Система Аньянова»**.

## 🎯 О проекте

**«Система Аньянова» (Anyanov System)** — это зонтичная архитектура человеческой целостности, объединяющая два фундаментальных контура:

1. ⚡ **«Внутренний ток» (Inner Current / Архитектура счастья):** инженерная система диагностики и восстановления внутреннего контура человека (генератор Тандэн, проводимость внимания $R \to 0$, ликвидация утечек, создание прорывных продуктов).
2. 🧲 **«Внешний магнетизм» (External Magnetism / Архитектура впечатления):** согласование внешнего физического присутствия через 4 измерения (Форма, Фактура, Цвет, Запах), создающее мощное силовое поле притяжения и достоинства.

Это преодоление главного кризиса современности — двойного разлада созидателя (потухший взгляд внутри + запущенный вид снаружи).

## 💡 6 Главных лампочек жизни (Многоканальный щит нагрузки)

В архитектуре системы выделены 6 базовых параллельных нагрузок, на которые подается ток человеческого внимания:

| № | Лампочка | Ключ | Роль в цепи |
| :-: | :--- | :--- | :--- |
| **1** | 🚗 **Машина** | `CAR` | Мобильность, динамика, свобода перемещения, автономия в пространстве |
| **2** | 🏡 **Дом** | `HOME` | Базовый контур безопасности, среда обитания, очаг, уют |
| **3** | 💼 **Карьера** | `CAREER` | Созидательное ремесло, профессиональное влияние, масштаб |
| **4** | ❤️ **Отношения** | `RELATIONSHIPS` | Любовь, близость, семья, эмоциональный резонанс с другими сознаниями |
| **5** | 🩺 **Здоровье** | `HEALTH` | Физический скафандр, биохимия, сон, запас витальности, долголетие |
| **6** | 🎉 **Развлечения** | `ENTERTAINMENT` | Игра, гедонизм, переключение, хобби, свежий дофамин и радость момента |

По **закону сохранения мощности ($P_{total} = \sum P_i$)** у каждого человека горят свои лампы. Одновременная попытка перегрузить все 6 каналов вызывает **просадку напряжения (Undervoltage)**, а полное обесточивание канала **Здоровье (0 Вт)** ради Карьеры приводит к выходу генератора из строя.

## 💻 Быстрый старт и запуск

### 1. Запуск интерактивного веб-интерфейса (Visualizer Dashboard & Book Reader)
```bash
npm start
```
Откройте в браузере:
* **Дашборд инженера и телеметрия:** **`http://localhost:3333/`**  
  * **1. Навигатор болей:** физика 5 главных человеческих страданий (выгорание, синдром самозванца, крах, апатия, перегруз) и точечный ремонт цепи.
  * **2. Дашборд счастья (Live Telemetry HUD):** объективный расчет индекса счастья $\mathcal{H}$, датчики $R, I, Q$, защита Дзансин, распределение 6 ламп и «Переводчик ощущений» в 3 клика.
  * **3. Атлас счастья & Десять быков Дзен (十牛図):** каноническое состояние сверхпроводимости ($R \to 0$), Тандэн, Ваби-саби и 10 ступеней эволюции оператора контура.
  * **4. Контур ядра (v1.0):** интерактивная схема цепи в реальном времени с ползунками сопротивления ума.
  * **5. Щит 6 ламп (v1.1):** многоканальная SVG-схема и пульт балансировки Кирхгофа.
* **Интерактивная электронная книга:** **`http://localhost:3333/book/`**  
  * Полный текст книги «Внутренний ток» с типографикой формул KaTeX, поиском, содержанием по 4 частям и адаптивным дизайном.

### 2. Запуск телеметрического симулятора (CLI)
```bash
npm run demo
```

### 3. Сборка электронной книги
```bash
npm run build:book
```

### 4. Запуск автоматических тестов
```bash
npm test
```
*34 из 34 инженерных тестов проходят на 100% со средней скоростью < 160ms (включая чистую физику электродинамики, Pain-First маппинг, валидатор телеметрии, онтологический атлас 23 канонов Дзен, 10 стадий Быков Дзен и валидацию визуализатора).*
