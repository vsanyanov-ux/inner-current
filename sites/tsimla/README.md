# 🌊 Однодневный тур по Цимле («Вдоль правого берега Цимлы»)

Автономный статический сайт авторского маршрута одного дня по правому берегу Цимлянского водохранилища.

## Структура сайта
- **index.html** — полностью автономная одностраничная вёрстка (Tailwind CSS CDN, Google Fonts, Font Awesome).
  - Floating Quick Bar (План, Образ, Карта)
  - Hero-секция с ключевыми параметрами тура (08:00–17:00, ~77 км, финал в 17:00)
  - Блок «Настроение дня: Свобода степи, морской бриз и уют»
  - Подробный таймлайн дня (8 ключевых локаций: ГЭС, Саркел, Правобережное городище, мельница Парамонова, видовой пикник, Петровские подвалы, возвращение, театр в ДК «Октябрь»)
  - Гардеробная капсула (день / вечер)
  - Интерактивный чек-лист сборов
  - Кнопка навигатора (готовый единый трек Google Maps)
